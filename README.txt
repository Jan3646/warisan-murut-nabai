WARISAN DIGITAL MURUT NABAI — PROTOTAIP

Kandungan:
- index.html: laman web dokumentasi satu halaman dengan menu navigasi dan bahagian berasingan.
- Setiap bahagian mempunyai anchor ID yang boleh digunakan untuk pautan terus, contohnya:
  index.html#bangkad
  index.html#manansigar
  index.html#sulou

PENTING:
1. Ini prototaip statik. Untuk orang ramai mengakses melalui internet, muat naik index.html ke hosting web seperti GitHub Pages, Netlify atau hosting institusi.
2. Selepas laman diterbitkan, gunakan URL awam penuh + anchor sebagai destinasi QR code. Contoh format:
   https://alamat-laman-anda/#bangkad
   https://alamat-laman-anda/#manansigar
3. QR code hanya akan berfungsi untuk pengunjung selepas URL awam diterbitkan.
4. Semak nama khas, fakta budaya, ejaan dan hak penggunaan gambar dengan pihak komuniti sebelum penerbitan rasmi.
